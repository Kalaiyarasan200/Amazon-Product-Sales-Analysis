# Amazon Product Sales Analysis

## Project Overview

This project performs an end-to-end Exploratory Data Analysis (EDA) on an Amazon Product Sales dataset using Python in Google Colab. The objective is to analyze product performance, customer behavior, pricing, discounts, and sales trends to generate meaningful business insights through data visualization.

The project demonstrates the complete data analysis workflow, including data cleaning, preprocessing, feature engineering, exploratory analysis, statistical summaries, and business-oriented visualizations.

## Tools and Technologies

* Python
* Google Colab
* NumPy
* Pandas
* Matplotlib
* Seaborn

## Visualizations Included

* Top 10 Best-Selling Products
* Revenue by Product Category
* Average Customer Ratings by Category
* Price Distribution
* Monthly Sales Trend
* Discount Percentage Distribution
* Correlation Heatmap
* Orders by Customer Region
* Payment Method Analysis
* Product Price Distribution by Category (Box Plot)
