# Amazon Product Sales Analysis

## Project Overview

This project performs an end-to-end Exploratory Data Analysis (EDA) on an Amazon Product Sales dataset using Python in Google Colab. The objective is to analyze product performance, customer behavior, pricing, discounts, and sales trends to generate meaningful business insights through data visualization.

The project demonstrates the complete data analysis workflow, including data cleaning, preprocessing, feature engineering, exploratory analysis, statistical summaries, and business-oriented visualizations.

## Objectives

* Clean and preprocess raw sales data.
* Analyze the best-selling products.
* Identify revenue generated by each product category.
* Evaluate customer ratings across categories.
* Understand product price distribution.
* Analyze monthly sales trends.
* Examine discount patterns.
* Compare product prices with customer ratings.
* Identify the highest revenue-generating products.
* Analyze regional sales and payment methods.
* Generate actionable business insights using visualizations.

## Dataset Features

The dataset contains the following information:

* Order ID
* Order Date
* Product ID
* Product Category
* Product Price
* Discount Percentage
* Quantity Sold
* Customer Region
* Payment Method
* Customer Rating
* Review Count
* Discounted Price
* Total Revenue
